Kamu chef-nya, pelanggan menunggu di pass. Di **Dapur Kilat** kamu berlari di antara
enam peti bahan, talenan, grill, meja rakit, dan pass sajian: potong selada, grill
patty sampai matang (jangan sampai hangus!), rakit burger sesuai resep — Klasik,
Keju Leleh, Kebun, Deluxe — lalu sajikan sebelum pelanggan kehabisan sabar. Wajah
pelanggan berubah dari senang ke kesal ke marah seiring bar kesabaran mereka
menipis, kombo beruntun melipatgandakan koin, dan shift 120 detik makin padat
dengan pesanan. Semua seni dibuat khusus untuk game ini (latar dapur, potret chef
dan pelanggan, hidangan hero) dan semua suara disintesis di dalam kode dengan
WebAudio — tanpa file eksternal, tanpa jaringan.

## Run it

```sh
# serve the game folder with any static server, then open it in a desktop browser
python3 -m http.server 8080 -d game
# open http://localhost:8080
```

Kontrol: **WASD / panah** bergerak, **E / Spasi** pakai stasiun, **1–6** ambil bahan,
**klik** untuk jalan ke stasiun, **P** jeda, **M** suara, **R** main lagi.
