DAPUR KILAT v2 is a guided Korean cooking-lesson game: customers arrive with orders for three Korean dishes that unlock one by one — Kimchi, then Bibimbap, then Tteokbokki. Each dish is a chain of tactile mini-steps in its own scene: collect ingredients by matching silhouettes, chop by swiping down a dashed line, pour by dragging the pitcher, stir with a circular drag, and grate by picking the right tool from three and dragging it until the progress bar fills (a wrong tool tells you at once, instead of stalling silently). A 120-second shift timer, draining patience bars, combo bonuses and 1–3 stars per served dish keep the rush on.

## Run it

```sh
python3 -m http.server 8080 --directory game
# open http://localhost:8080 in a desktop browser
```
